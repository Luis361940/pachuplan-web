Política de Privacidad

Última actualización: 8 de septiembre de 2026

PachuPlan es una plataforma que permite descubrir, crear y participar en planes y actividades, interactuar con otros usuarios y comunicarse dentro de los planes disponibles en la plataforma.

Esta Política de Privacidad explica qué información tratamos, para qué la utilizamos y qué opciones tienen los usuarios respecto de sus datos.

1. Información que tratamos

Información de cuenta

  • Nombre.
  • Dirección de correo electrónico.
  • Contraseña almacenada mediante un hash seguro.
  • Fotografía de perfil, cuando el usuario decide proporcionarla.

PachuPlan no almacena contraseñas en texto plano.

Ubicación

PachuPlan puede solicitar acceso a la ubicación del dispositivo para mostrar planes cercanos, calcular distancias, centrar el mapa y facilitar la selección de lugares.

La ubicación actual usada para estas consultas no se utiliza para crear un historial permanente de movimientos del usuario. Los lugares asociados a planes sí pueden contener coordenadas geográficas necesarias para mostrar dónde se realizará una actividad.

Contenido generado por usuarios

Podemos almacenar planes creados, participaciones, lugares asociados a planes, mensajes de chat y reportes realizados sobre usuarios, planes o mensajes.

Recuperación de contraseña

Cuando se solicita recuperar una contraseña, PachuPlan puede generar códigos temporales de verificación. Estos códigos se almacenan de forma protegida y tienen vigencia limitada.

2. Para qué utilizamos la información

  • Crear y administrar cuentas.
  • Autenticar usuarios.
  • Mostrar perfiles y planes cercanos.
  • Permitir crear, descubrir y participar en planes.
  • Habilitar chat y mostrar participantes.
  • Gestionar fotografías de perfil.
  • Recuperar cuentas.
  • Recibir y revisar reportes.
  • Prevenir abuso, fraude, spam y conductas contrarias a nuestras normas.

No vendemos información personal de nuestros usuarios.

3. Proveedores tecnológicos

PachuPlan utiliza proveedores que pueden procesar información en la medida necesaria para operar la plataforma:

  • Render / PostgreSQL: infraestructura de backend y almacenamiento de datos.
  • Cloudflare R2: almacenamiento de archivos como fotografías de perfil.
  • OpenStreetMap: visualización cartográfica.
  • Servicios de correo electrónico: envío de comunicaciones transaccionales como códigos de recuperación de contraseña.

4. Seguridad

Aplicamos medidas técnicas razonables, entre ellas hash de contraseñas, autenticación mediante tokens, HTTPS en producción y almacenamiento protegido de códigos de recuperación. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

5. Conservación y eliminación

Conservamos información mientras sea necesaria para proporcionar PachuPlan, mantener la seguridad o cumplir obligaciones legales aplicables.

Cuando un usuario elimina su cuenta, PachuPlan elimina o desvincula información asociada conforme a la funcionalidad del sistema. Algunos registros relacionados con seguridad o reportes pueden conservarse de forma anonimizada cuando sea necesario para proteger la plataforma y sus usuarios.

6. Fotografías

Las fotografías de perfil pueden almacenarse en Cloudflare R2. Cuando una fotografía se reemplaza o una cuenta se elimina, PachuPlan intenta eliminar el archivo correspondiente. Una falla técnica excepcional podría retrasar su eliminación.

7. Permisos del dispositivo

  • Ubicación: para mapas y planes cercanos.
  • Galería/Fotografías: para seleccionar una fotografía de perfil.

El usuario puede administrar estos permisos desde la configuración de su dispositivo.

8. Menores de edad

PachuPlan está dirigido exclusivamente a personas de 18 años o más. Si tenemos conocimiento de una cuenta perteneciente a un menor, podremos suspenderla o eliminarla.

9. Cambios

Podemos actualizar esta política cuando cambien nuestras funcionalidades, prácticas o requisitos legales. Cuando corresponda, comunicaremos cambios relevantes mediante la aplicación u otros medios razonables.

10. Contacto

Para privacidad, datos personales o eliminación de cuenta: pachuplan@gmail.com.
